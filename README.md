# 🎓 YouTube AI Notes Studio

An AI-powered study assistant that converts YouTube video transcripts into clear notes, summaries, definitions, and revision questions using Gemini.

## 🚀 Try the Live Agent

### 👉 [**Open YouTube AI Notes Studio**](https://youtube-ai-notes-studio.onrender.com/)

Generate study notes from YouTube videos and download them as TXT or PDF files.

## ✨ Features

* 📝 Generate clear study notes and summaries
* 📚 Extract important definitions
* ❓ Create revision questions
* 📄 Download notes as TXT or PDF
* 🤖 Powered by Google Gemini
